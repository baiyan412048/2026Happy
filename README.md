# 2026Happy

快樂航空 Happy Air 桃園（TPE）→ 釜山（PUS）禮物機票頁。

## 修改內容

打開 `index.html`，找到最下方的 `CONFIG`，修改內容：

- `code`：訂位代號（顯示在條碼下方）
- `passenger` / `companion`：旅客與同行旅客姓名
- `message` / `from`：登機證上的文字
- 其他：日期、座位、登機門、艙等、飛行時間、行李、旅客須知
